🚀 Guía rápida: Gemini y Sincronización

  1. API Key gratuita de Gemini: Entra en aistudio.google.com/apikey con tu cuenta Google, pulsa "Create API key" y copia la clave (AIzaSy...).
  2. Configurar IA: Pega la clave abajo en Google AI Studio API Key, pulsa Guardar clave y luego 🔄 Actualizar modelos.
  3. Modo A y Modo B: Con Modo A la app detecta producto y fecha automáticamente tras la foto. Si la API está saturada o no quieres usar clave, pulsa Modo B para enviar la foto directamente a tu app oficial de Gemini y pegar su respuesta.
  4. Sincronización en la nube (Firebase): Crea un proyecto web en Firebase, activa Authentication (Google) y Firestore Database, pega el bloque firebaseConfig arriba y pulsa G Entrar en la cabecera.
  5. Gestos y alertas: Desliza cualquier producto hacia la izquierda para borrarlo (con botón Deshacer). Usa 📅 para añadir una alarma a tu calendario.
💡 Consejo: Encuadra en la misma foto el nombre del envase y la fecha impresa para mayor precisión.
