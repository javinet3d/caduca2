📖 Manual de ayuda: Configurar Gemini y App

🚀 Guía rápida: Gemini y Sincronización

  1. API Key gratuita de Gemini: Entra en aistudio.google.com/apikey con tu cuenta Google, pulsa "Create API key" y copia la clave (AIzaSy...).
  2. Configurar IA: Abre el apartado 🤖 API Key y Modelo de Gemini, pega la clave, pulsa Guardar clave y luego 🔄 Actualizar modelos.
  3. Fotos guardadas en cada producto: Puedes adjuntar hasta 3 fotos por producto. Se guardan comprimidas en color (~20 KB) y luego puedes verlas pulsando el botón 🖼️ de su tarjeta.
  4. Modo A y Modo B: Con Modo A la app detecta producto y fecha automáticamente con gemini-3.1-flash-lite. Si hay saturación o no tienes clave, usa Modo B para enviar las fotos a tu app oficial de Gemini y pegar su respuesta.
  5. Instalar a pantalla completa: En Chrome Android pulsa 📲 Instalar arriba (o menú ⋮ > Instalar aplicación) para usar Caduca2 sin barra de navegador.
💡 Consejo: Puedes borrar cualquier producto pulsando 🗑️ o deslizándolo hacia la izquierda; aparecerá abajo el botón ↩️ Deshacer durante 6 segundos.
